# Эксперимент: ROI, выдержка и частота кадров

Камера MV-AX5F57MP050E, Magewell Flex I/O Quad CXP-12 Enhanced, CXP12_X4, Mono8.

Значения — принятые кадры/с; при повторах показана медиана. Звёздочка означает пропуски frame_id, скачки назад, таймауты или ошибку хотя бы в одном повторе. Отсутствие пропусков frame_id само по себе не исключает торможение камеры при нехватке DMA-буферов.

`discard` возвращает DMA-буфер без копирования; `copy` делает memcpy каждого кадра в один переиспользуемый RAM-буфер. Весь видеопоток в памяти не сохраняется. Дисковая запись кадров и GUI в измерении не участвуют.
